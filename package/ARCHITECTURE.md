# 구성도와 신뢰 경계

완성한 제품의 구성도 그림을 `package/` 안에 넣고 이 문서에서 연결하세요. 그림에는 브라우저, 자료 함수(`/api/notes`), AI 중계(`/api/ai`), 침해 정보(`/api/threat-intel`), Supabase, 외부 AI API, NVD·CISA KEV를 표시하세요.

- 로그인 세션이 지나는 경로: (실제 구현을 보고 적으세요)
- 서버가 허용·거절을 판단하는 위치: (실제 구현을 보고 적으세요)
- 브라우저가 수행하는 화면·분석 작업: (실제 구현을 보고 적으세요)

`/api/notes`는 서버 전용 Supabase 키로 메모를 읽지만 로그인 없이 호출할 수 있어 메모가 공개됩니다. `api/ai.js`와 `api/threat-intel.js`는 아직 미구현 상태로 501을 반환합니다. 완성 전 구성도나 보안 기능을 확인한 증거로 쓰지 마세요.
